LadMichHoch

A personal video upload tool for TikTok

What it does

LadMichHoch is a small desktop program that runs on the owner's own computer. It uploads the owner's own videos to the owner's own TikTok account, so they do not have to be posted by hand.

How it works

  1. The owner logs in once with TikTok and allows the program to post videos.
  2. The program takes a video file from a folder on the computer.
  3. The program sends the video to TikTok through the official TikTok Content Posting API.

LadMichHoch is a private, non-commercial project. It is not offered to the public and is not affiliated with TikTok.
