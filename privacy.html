Privacy Policy

Last updated: November 19, 2026

1. Overview

LadMichHoch is a private desktop program that uploads videos to a TikTok account. It runs only on the owner's own computer. There is no server and no database operated by LadMichHoch.

2. Data the program uses

  • TikTok access tokens: after the account owner logs in with TikTok, TikTok gives the program an access token and a refresh token. They are needed to upload videos.
  • Basic TikTok account information: the account's ID and the posting options TikTok allows for it, such as available privacy settings.
  • Video files and captions: the videos and texts the owner chooses to upload.

3. How the data is used

The data is used only to upload the chosen videos to the connected TikTok account. It is not used for advertising, analytics or profiling.

4. Where the data is stored

Access tokens are stored only in a local file on the owner's computer. Video files stay on the owner's computer and are sent only to TikTok.

5. Sharing of data

Data is sent only to TikTok, through the official TikTok API. It is not sold and not shared with anyone else.

6. Removing access and deleting data

Access can be removed at any time in the TikTok app under Settings, Security and permissions, Manage app permissions. Deleting the local token file on the computer removes all stored access data.

7. This website

This website does not use cookies or tracking. The hosting provider may record technical data such as IP addresses in its server logs.

8. Changes

This policy may be updated. The current version is always published on this page.
